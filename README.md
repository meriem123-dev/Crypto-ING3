## Crypto ING3

Application de chiffrement et de déchiffrement développée en Python avec **CustomTkinter**, offrant une interface graphique moderne pour expérimenter plusieurs algorithmes cryptographiques classiques.

**Algorithmes implémentés :**
- Polybe
- Playfair
- Hill
- Transposition
- DES (Data Encryption Standard)

**Technologies :** Python, CustomTkinter, NumPy.

Ce projet permet de comprendre et de manipuler différents mécanismes de chiffrement à travers une interface interactive, dans un cadre pédagogique.
